## Уровни моделирования (для текста диплома)

1. **Концептуальная** — сущности предметной области (пользователь, профиль, приём пищи, отчёт) без привязки к таблицам и СУБД.
2. **Логическая** — атрибуты, типы, связи; допускается указание «логических» таблиц без серверов.
3. **Физическая** — конкретные БД (`allergen_pg`, `user_pg`, `health_tracker`, `report_pg`), индексы, типы СУБД, Redis, Kafka.
